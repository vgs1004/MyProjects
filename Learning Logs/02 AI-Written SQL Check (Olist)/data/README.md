# Data

Three tables from the **Brazilian E-Commerce Public Dataset by Olist**:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

| File | Rows | Used for |
|---|---:|---|
| `olist_orders_dataset.csv` | 99,441 | order status and purchase date |
| `olist_order_items_dataset.csv` | 112,650 | price and shipping per item |
| `olist_order_payments_dataset.csv` | 103,886 | what customers paid (one order can have several payment rows) |

Licence: CC BY-NC-SA 4.0, by Olist. Real, anonymised commercial data; no employer data.

These are unchanged copies of the original Kaggle files, kept here so the log can be repeated.
