# Data

Three tables from the **Brazilian E-Commerce Public Dataset by Olist**:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

| File | Rows | Used for |
|---|---:|---|
| `olist_orders_dataset.csv` | about 99,000 | order status and purchase date |
| `olist_order_items_dataset.csv` | about 112,000 | price and shipping per item |
| `olist_order_payments_dataset.csv` | about 104,000 | what customers paid (one order can have several payment rows) |
